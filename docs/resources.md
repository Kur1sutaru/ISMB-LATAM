# Resources / Recursos

## Cell type annotation: databases, atlases and tools / Anotación: bases de datos, atlas y herramientas

| Resource / Recurso | What it is / Qué es | Link |
|---|---|---|
| PanglaoDB | Curated marker genes (human, mouse) / Marcadores curados | <https://panglaodb.se> |
| CellMarker 2.0 | Manually curated markers / Marcadores curados manualmente | <http://bio-bigdata.hrbmu.edu.cn/CellMarker/> |
| CZ CELLxGENE Discover | Standardized, annotated datasets; Explorer; Gene Expression; Census API / Conjuntos estandarizados y anotados | <https://cellxgene.cziscience.com> |
| CELLxGENE Census (Python/R) | Programmatic access to CELLxGENE data / Acceso programático | <https://chanzuckerberg.github.io/cellxgene-census/> |
| Single Cell Portal (Broad) | Hundreds of studies, interactive plots, downloads / Cientos de estudios | <https://singlecell.broadinstitute.org> |
| Cell Annotation Platform (CAP) | Record, evidence and share cell type annotations / Registrar y compartir anotaciones | <https://celltype.info> |
| Human Cell Atlas Data Portal | HCA data and references / Datos y referencias del HCA | <https://data.humancellatlas.org> |
| Cell Ontology (CL) | Standard cell type IDs / IDs estándar de tipos celulares | <https://www.ebi.ac.uk/ols4/ontologies/cl> |
| CellTypist | Pre-trained classifiers / Clasificadores preentrenados | <https://www.celltypist.org> |
| Azimuth (R/web) | Reference mapping / Mapeo a referencia | <https://azimuth.hubmapconsortium.org> |
